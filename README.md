# Madurai Best Taxi - Official Website

A modern, high-performance website for **Madurai Best Taxi**, inspired by and modeled after `maduraitourtaxi.com`.

## 🚖 Features
- **Instant Cab Booking Engine:**
  - Outstation, Local Day Rental, and Airport Transfers
  - Tamil Nadu district selection
  - 1-Click WhatsApp Booking with pre-formatted message
  - Direct Call booking
- **Fleet & Transparent Tariff:**
  - Swift Dzire, Maruti Ciaz, Prime SUV Ertiga, Innova Crysta, Tempo Traveller (12 & 18 Seater)
  - Toggle between **Outstation Plan (Per Km)** and **Day Rental Plan (Base Rent + Km)**
- **Curated Tour Packages:**
  - Madurai Heritage Tour, Rameswaram Pilgrimage, Kodaikanal Hill Tour, Kanyakumari, Munnar, South Temple Circuit
  - Detailed itinerary modal & instant WhatsApp enquiry
- **Customer Reviews & FAQs:**
  - Verified reviews & accordion FAQ section
- **Multi-language Support:**
  - English & தமிழ் (Tamil) switch in the navbar
- **Floating Call & WhatsApp Action Buttons**

## 🚀 How to Run Locally

1. Open PowerShell in `G:\Madurai Best Taxi`:
   ```bash
   npm run dev
   ```
2. The website will open at `http://localhost:3000` (or `http://localhost:5173`).

## 📦 How to Build for Production

```bash
npm run build
```
Production output files will be created in the `dist/` folder.
